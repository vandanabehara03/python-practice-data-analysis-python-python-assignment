# Day 1 Notes — Introduction to Python & Getting Started

## What is Python?
Python is a programming language. A programming language is simply a way to give instructions to a computer in a format the computer can understand.
Just like you use English to talk to people, you use Python to talk to your computer.

## Why Python for Business?
- Companies like Amazon, Netflix, Flipkart, and Google use Python every day
- It can do in seconds what would take hours in Excel
- It is free, beginner-friendly, and in very high demand for jobs

## Setting Up — Jupyter Notebook
We write Python code inside the Jupyter Notebook. Think of it as a smart document where you can write code, run it, and see the result immediately — all in one place.

### How to open it:
1. Open Anaconda Navigator
2. Click Launch under Jupyter Notebook
3. A browser tab opens — this is where you work

### A Notebook is made of Cells:
- **Code Cell** - where you write Python code
- **Markdown Cell** - where you write plain text notes
- **To run a cell** - press Shift + Enter

## Your First Python Program

### Program 1: Hello, World!
```python
print("Hello, World!")
```

`print()` is a function that displays output on the screen. Whatever you put inside the brackets gets displayed.

### Program 2: Introduce Yourself
```python
print("My name is Vandana")
print("I am learning Python for Business")
```

**Output:**
```
My name is Vandana
I am learning Python for Business
```
